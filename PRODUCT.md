# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Chrome Manifest V3 with HTML, CSS and JavaScript. The popup runs entirely inside the extension.

## Users

Kim and Coco are the first desktop Chrome testers. They read English articles and technical documentation and work with GitHub.

## Product Purpose

Translate the current page into Simplified Chinese on request and restore the original in place. Keep GitHub's local interface translation independently controllable.

## Operating Context

The browser popup is a short, keyboard-accessible task surface. It presents configuration, a clear send confirmation when required, and the status of the current page. Users bring their own DeepSeek API Key.
